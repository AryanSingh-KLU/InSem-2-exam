# Notification Messages (React Props)

A simple React application demonstrating a reusable `Notification` component.

## Props

- `message`: The text displayed in the notification.
- `type`: The notification style. Use `info` for blue or `warning` for orange.

## Run locally

1. Install [Node.js](https://nodejs.org/).
2. Open this project folder in VS Code.
3. Open the terminal in VS Code and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL shown in the terminal.

## Build

Run `npm run build`. The production-ready website files will be created in the `dist` folder.

## Run from GitHub

GitHub stores the source code; it does not run a React project just by opening the repository. You can publish the built site with GitHub Pages using a deployment workflow or deploy it through a hosting service such as Vercel.
